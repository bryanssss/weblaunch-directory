About the project

A fairer place to discover the independent web

WebLaunch Directory is an open-source project built for useful websites that may not have a large advertising budget.

Why this directory exists

Search results and social feeds often favour established brands, paid campaigns and already-popular websites. This directory gives small tools, personal projects, specialist blogs and useful independent services another place to be discovered.

How it works

Website owners submit their main homepage for free. The system automatically checks basic rules, including secure HTTPS, homepage-only addresses, daily limits and suspicious redirects. A moderator then decides whether the listing should be approved.

Open-source by design

The project code can be inspected, improved and self-hosted. The public repository includes the website, Cloudflare Pages Functions, D1 database schema, moderation dashboard and deployment guide.

What the directory does not promise

Approval is not an endorsement. The directory cannot continuously guarantee the safety, legality, accuracy or availability of every external website. Visitors should use their own judgement and report listings that become broken or misleading.
