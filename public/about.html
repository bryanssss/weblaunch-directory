About the project

A fairer place to discover the independent web

WebLaunch Directory is an open-source project built for useful websites that may not have a large advertising budget.

Why this directory exists

Search results and social feeds often favour established brands, paid campaigns and already-popular websites. This directory gives small tools, personal projects, specialist blogs and useful independent services another place to be discovered.

How it works

Website owners submit their main homepage for free. The system checks HTTPS, homepage-only URLs, daily limits, duplicates, suspicious redirects, affiliate patterns and high-confidence prohibited-content signals. Eligible websites are then published automatically.

Safety after publication

Automatic checks reduce obvious abuse but cannot guarantee that every website is safe, lawful or unchanged. Every listing page includes a link to the private contact form, where visitors can report broken, misleading, pornographic, malicious or otherwise prohibited listings. Messages are saved in a protected Cloudflare D1 inbox for the directory administrator. The operator can suspend or remove them.

Open-source by design

The project code can be inspected, improved and self-hosted. The public repository includes the Worker, static website, D1 database schema, reporting tools, directory-management dashboard and deployment guide.

What the directory does not promise

Inclusion is not an endorsement, certification or guarantee. Visitors should use their own judgement before relying on, purchasing from or sharing information with an external website.

Supporting the project

Listings remain free and donations are optional. A donation does not affect automatic eligibility, ranking, featured placement or removal decisions.
