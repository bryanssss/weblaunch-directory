Privacy

Privacy notice

The directory collects only the limited information needed to review submissions and reduce abuse.

Information processed during a submission

The form receives the website name, homepage address, description, category and submitter email address. The email address is immediately transformed into a one-way cryptographic hash before database storage. The raw email address is not stored by this application.

The visitor’s IP address is also transformed using a private server-side salt. Only the resulting hash is stored. The hash is used to apply the two-submission daily limit and help prevent repeated abuse.

Turnstile

The submission form uses Cloudflare Turnstile to distinguish normal visitors from automated spam. Cloudflare may process technical information needed to provide that security service.

Reports

When a visitor reports a listing, the report reason, optional details and a hashed version of the visitor’s IP address are stored. This helps prevent repeated reports from the same source.

Retention

Approved, pending, rejected and suspended submission records may be retained so duplicate domains cannot be repeatedly submitted. Daily counter records are automatically cleaned after a short period. Moderators may delete records when they are no longer needed.

External websites

Listings link to independent external websites with their own privacy practices. WebLaunch Directory is not responsible for how those websites collect or use information.

Your choices

Do not submit personal information in a website description or report. A site owner may contact the directory operator using the contact method published in the repository to request correction or removal.

Owner note: Before launch, replace this general notice with contact details and any additional wording required for your location and organisation.
