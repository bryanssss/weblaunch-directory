# 🌐 WebLaunch Directory

**WebLaunch Directory** is a free, open-source website directory where eligible independent websites can be discovered and published automatically.

Every submission is checked for spam, affiliate links, suspicious redirects, duplicate domains, unavailable websites and prohibited content before it can appear publicly.

## ✨ Main Features

### Automatic Website Publication

Submissions can be published immediately when they pass the automated checks.

The system validates:

- HTTPS availability
- Homepage-only URLs
- Website response status
- Same-domain redirects
- Duplicate domains
- Affiliate and referral parameters
- Tracking parameters
- URL shorteners
- Suspicious deep links
- Prohibited content signals
- Daily email and IP-derived submission limits
- Cloudflare Turnstile verification

### Free and Fair Listings

WebLaunch Directory does not sell directory positions.

- No paid placement
- No paid ranking advantages
- No affiliate links
- No referral links
- No sponsored directory position
- No registration requirement
- Maximum two submissions per day per email hash
- Maximum two submissions per day per IP-derived hash

Optional donations help support the project but do not affect eligibility, ranking, visibility or removal decisions.
