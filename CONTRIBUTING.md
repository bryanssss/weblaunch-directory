# Contributing

Thank you for helping improve WebLaunch Directory.

## Good Contributions

- Fixing bugs or accessibility issues
- Improving tests
- Strengthening validation without blocking normal websites unnecessarily
- Improving moderation tools
- Improving documentation
- Translating the interface

## Before Opening a Pull Request

1. Create a branch.
2. Keep the change focused.
3. Run `npm test`.
4. Run `npm run check`.
5. Explain what changed and how it was tested.

Do not include API keys, Cloudflare secrets, private IP data, real submission records or other personal information.
